# Assigned Job

Create the title and body for a GitHub pull request.

You will receive verified evidence from a completed Contrigent run:

- the original GitHub issue and comments
- the Manager's analysis
- each worker's summary and findings
- each changed file and the worker's reason for changing it
- the Independent Reviewer's result
- the real repository test result
- the Contrigent branch name
- the created commit SHA
- the GitHub issue number

Use this evidence to explain:

1. what problem the pull request fixes
2. what was changed
3. why those changes were made
4. what regression or verification work was performed
5. whether the repository test suite passed
6. the Independent Reviewer's conclusion

The pull request body should normally contain:

## Summary

## Changes

## Testing

## Review

and finish with:

Closes #<issue number>

Write for a human open-source maintainer reviewing the contribution.
