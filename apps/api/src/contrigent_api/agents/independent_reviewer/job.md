# Assigned Job

Review the combined proposed solution against:

- the original issue
- the issue acceptance criteria
- repository instructions
- the approved implementation plan
- relevant original repository files
- worker assignments
- worker results
- combined proposed replacement files

Check:

- whether the issue is actually addressed
- whether the proposed changes match the approved plan
- whether unnecessary files were changed
- whether repository instructions were followed
- whether different workers produced compatible work
- whether obvious bugs or regressions are present
- whether the solution exceeds the approved scope

Return a structured review.

Recommend `approve` only when the proposed solution is suitable to proceed to human final approval.

Recommend `changes_required` when meaningful problems remain.
